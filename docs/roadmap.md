# 開発計画・検証

## 段階

1. **基礎調査**：実際のChromeOS端末の入力方法とWebGL性能、同時人数、ネットワーク条件、保護者の管理方法を確認する。ホスティングと概算費用を比較する。
2. **共同編集の縦切り**：仮の認証で2ブラウザを接続し、サーバー確定、競合、永続化、再接続を通して検証する。
3. **招待と管理**：大人の認証、期限付き招待、失効、バックアップと復元を実装する。
4. **子ども向け体験**：参加画面、名前候補、参加者表示、操作説明、接続状態、エラー表示を整える。タッチ操作の要否は実機調査後に決める。
5. **実機テストと限定試用**：ChromeOS端末と家庭回線で複数人テストし、操作や性能の問題を直す。公開前に対象地域の子どものデータ取扱いを確認する。

## 必要な検証

- 二人による同じ座標の競合、重複送信、操作の到着順の入れ替わり。
- 接続の一時切断、保存直前の切断、サーバー再起動、再同期中の編集。
- 招待期限切れ・失効、別ワールドへの不正操作、参加中の失効。
- 世代復元後の全員の再同期と復元前状態の保全。
- ChromeOS実機での描画性能、キーボード、トラックパッド、必要に応じてタッチ操作。
- 参加・保存・失敗表示を子どもと大人が理解できるか。

## 未決事項

- 管理者アカウントの作成方法、対象地域、保護者の同意方法。
- 参加上限、ワールドサイズ、招待期限、バックアップの保持期間。
- タッチ操作の必須度、対応するChromeOS端末の型番。
- 実運用のホスティング、運用者、費用とサービス継続方針。

現行の試作版にはマルチプレイ、管理者権限、サーバー保存はまだない。設計上の方式は、実装と実機検証の結果に応じて更新する。
