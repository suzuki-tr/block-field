# プロダクト・要件（初版）

## 目的と前提

家庭や友達同士で、小学生の少人数グループが一つの建築を楽しむ。最初の対象はChromeOS端末のChrome。キーボード・マウス／トラックパッドを基本とし、タッチ対応の要否は端末調査後に決める。現時点の数値は設計上の仮定であり、利用実態に合わせて検証する。

## 最初の完成形（MVP）

- 大人がワールドを作成し、招待リンクを知る仲間が参加できる。初期目標は同時4人、上限8人。
- プレイヤーは表示名と色を選び、同じワールド内の他の参加者の位置を見られる。
- ブロックの設置・破壊が参加者全員に反映され、自動保存される。
- 接続が切れても、再接続時に最新のワールドを読み直せる。
- 大人は招待を無効化でき、ワールドを以前の保存状態に戻せる。誤操作を減らすため復元には確認を設ける。
- 操作説明、接続状態、保存状態、操作失敗を子どもにも分かる言葉で表示する。
- 自由入力チャット、公開ワールド検索、フレンド検索、音声通話、課金はMVPに含めない。表示名は用意した候補から選ぶ。

## 利用の流れ

1. 大人が管理者アカウントでログインし、ワールドを作成する。
2. 大人が期限付きの招待リンクを家族や友達に共有する。
3. 子どもは表示名候補と色を選び、参加する。参加前に読み込みと操作の説明を示す。
4. 一緒に建築する。画面には接続状態と参加人数を表示する。
5. 編集は自動保存。次回は有効な招待から参加し、続きに取り組む。
6. 大人は参加用リンクを無効化し、必要ならバックアップを復元する。

## 子ども向けの設計

本名、メールアドレス、プロフィール画像を子どもに求めない。自由入力や外部への公開をMVPに含めず、招待リンクは秘密情報として扱う。リンクの期限切れ・無効化・再発行と、参加者の退出操作を用意する。招待先の本人確認はリンクだけでは保証できないため、リンクを知っている人が再共有できることを大人に明示する。大人の管理操作は子どもの参加権限と分離する。対象地域の年齢・保護者同意・データ取扱いの要件は公開前に確認する。

## 受け入れ条件

- 2台以上で同じ部屋に入り、片方の設置・破壊が他方に表示される。
- 同じ座標への同時編集はサーバーが決めた順番で全員が同じ状態になる。
- 切断中の編集は送信できないことが明示され、再接続後は最新状態に戻る。
- 部屋を閉じて再参加しても、確定済みの建築が残る。
- 無効化済みの招待では新規参加できず、既存接続も切断される。
- ChromeOS実機で読み込み、移動、視点操作、設置・破壊、再接続を確認する。
