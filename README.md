# BLOCK FIELD

小学生が友達と一緒にブロック建築を楽しむブラウザゲーム。現在の `dist/` は一人用の試作版です。複数人機能は設計段階で、まだ実装されていません。

## 試作版を動かす

`dist/` を静的Webサーバーで配信します。例：

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000` を開きます。キーボード・マウスまたはタッチ画面で操作できます。タッチ操作は開始画面で「タッチであそぶ」を選び、左のスティックで移動、画面のドラッグで視点を変えます。ワールドはブラウザのローカルストレージに保存されます。
