# BLOCK FIELD

小学生が友達と一緒にブロック建築を楽しむブラウザゲーム。現在の `dist/` は一人用の試作版です。同じネットワークの2人で遊べるWebRTC試作版を含みます。

## 試作版を動かす

`dist/` を静的Webサーバーで配信します。例：

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000` を開きます。キーボード・マウスまたはタッチ画面で操作できます。タッチ操作は開始画面で「タッチであそぶ」を選び、左のスティックで移動、画面のドラッグで視点を変えます。ワールドはブラウザのローカルストレージに保存されます。

## ふたりで遊ぶ（試作）

同じWi-Fiに接続した2台で、それぞれアプリを開きます。ホストと参加者が「ふたりで」を押し、ホストが「ホストになる」、もう一人が「参加する」を選びます。ホストの招待コードを参加者へ渡し、参加者が貼り付けて決定します。参加者の返答コードをホストへ渡し、ホストが貼り付けて決定すると接続します。コードは長いためコピー＆ペーストしてください。

ホストがワールドを保持し、共同編集を自動保存します。ホストの切断で部屋は終了し、参加者の元のローカルワールドに戻ります。WebRTCの接続情報をコードで直接交換し、シグナリング、STUN、TURNサーバーは使いません。ネットワークの端末間通信制限やブラウザのWebRTC設定によっては接続できません。2台の実機での検証が必要です。掲載先がアクセス制限されている場合、両方の参加者に閲覧権限が必要です。

テスト：`node tests/multiplayer.test.mjs`（通信を模擬した同期・切断テスト）
